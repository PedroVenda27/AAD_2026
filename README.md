# AAD 2026/2027

Trabalhos práticos da cadeira de Arquiteturas de Alto Desempenho.

## Estrutura

- `P1/` — Laboratório 1: medição de desempenho do MandelbrotCount em várias linguagens (C, Java, Python, Fortran, Rust, WebAssembly, codon)
- `P2/` — Laboratório 2: paralelização com pthreads (mutexes, condition variables) e 4 versões paralelas do MandelbrotCount (faixas estáticas verticais/horizontais, região crítica, produtor/consumidor)
